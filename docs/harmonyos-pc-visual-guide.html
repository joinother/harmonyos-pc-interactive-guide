关于 WindowMode.FULL_SCREEN： 官方 window-mode-overview 把"用户点击最大化按钮"列为 FULL_SCREEN 触发条件，但 application-adaptation-freeform-window 与 games-adapt-pc-platform 均明确系统最大化按钮进入的是 MAXIMIZE（保留标题栏/三键/Dock/状态栏）。本页采信后者（与用户实测一致）。FULL_SCREEN 在 PC 自由窗口形态下与 MAXIMIZE 表现趋同，差异主要在平板/手机等非自由窗口形态。

PART 03

设置光标 · 代码示例

setCursor / .cursor() / restoreDefault / setCustomCursor，含版本与限制。

① 切换系统内置样式（推荐 UIContext）

// 推荐：通过 UIContext 获取 CursorController const cc = this.getUIContext().getCursorController(); cc.setCursor(pointer.PointerStyle.HAND_POINTING); // 下一帧生效 cc.restoreDefault(); // 恢复默认箭头 // 组件属性方式：hover 自动切、移出自动恢复 Button('链接').cursor(pointer.PointerStyle.HAND_POINTING); // 底层接口（需先拿 windowId） pointer.setPointerStyle(windowId, pointer.PointerStyle.TEXT_CURSOR, () => {});

② 自定义图片光标

// CursorController 版本（API 26.0.0+，全设备） cc.setCustomCursor(pixelMap, 16, 16); // pixelMap: image.PixelMap；focusX/Y: 热点，默认 0，范围 [0, 图片宽/高] // pointer 模块版本（API 11+，phone 12+/2in1 13+/tablet 12+/tv 19+） pointer.setCustomCursor(windowId, pixelMap, 16, 16).then(() => {});
限制（官方原文）：① 仅支持静态图片，不支持 GIF/APNG/WebP 等动态图；② 图片最大 256×256 px，超限本次设置不生效；③ 调用后下一帧生效；④ 作用域仅限本应用进程内窗口；⑤ 窗口布局改变、热区切换、页面跳转、光标移出再回、光标在窗口不同区域移动——光标可能切回系统样式，需重新设置。

③ 隐藏 / 显示系统光标

pointer.setPointerVisible(false, (err) => {}); // 隐藏（当前进程所有窗口） pointer.setPointerVisible(true, (err) => {}); // 显示 // 同步版本：setPointerVisibleSync(visible) （API 10+）
系统内置动画光标：LOADING(42)、RUNNING(43)、RUNNING_LEFT(45)、RUNNING_RIGHT(46) 是系统渲染的动画光标，应用只能选用，不能自定义动画内容。自定义图片光标不支持动画，要做旋转等动效请隐藏系统光标后在应用内自绘跟随图层（详见 harmonyos-cursor.md 第七节）。
